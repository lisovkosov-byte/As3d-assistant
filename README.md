---

## 🌟 Ключевые возможности

### 🎙 Режим «Live» (Голосовой помощник как Алиса / Алекса)
- **Активация по имени**: просто скажите вслух **«Астрид»** или сразу команду: *«Астрид, включи ютуб»*.
- **Звуковой сигнал**: приятный двухтоновый сигнал активации («динь-дон»).
- **Живая нейросетевая речь**: озвучка ответов естественным русским голосом («Светлана» от Microsoft Edge Neural TTS).
- **Кнопка «🎤 СКАЗАТЬ»**: для быстрого ввода голосом без кодового слова.
- **Тумблер звука**: `[ 🔊 ОЗВУЧКА: ВКЛ / ВЫКЛ ]` в шапке окна.

### ⚡ Визуальный редактор пресетов и Авто-кликер
- Создание цепочек действий для любых задач:
  - **💻 Программы**: запуск `.exe`, ярлыков, батников (выбор через проводник в один клик).
  - **🌐 Сайты**: открытие любых ссылок в браузере.
  - **⏳ Паузы**: задержка между шагами в секундах.
  - **🪟 Фокус окна**: автоматический вывод нужного окна на передний план (например, окна VPN).
  - **⌨ Клавиатура**: программное нажатие любых клавиш (`Enter`, `Space`, `Tab`, `Esc`, `F11`, `Ctrl+C`).
  - **🖱 Мышь с авто-захватом координат**: таймер на 3 секунды позволяет просто навести мышь на кнопку на экране — координаты запишутся сами!
  - **📝 Ввод текста**: авто-печать заданного текста.
- **Сортировка шагов**: удобные кнопки `▲ Вверх` и `▼ Вниз`.
- **Голосовые триггеры**: привязка фраз для мгновенного запуска (`ютуб, youtube, ютубчик`).

### 🚀 Автозапуск Windows
- Встроенный переключатель в настройках: запускает Астрид автоматически при старте компьютера через реестр Windows.

### 🧠 Универсальный ИИ-мозг
- **OpenRouter (Бесплатно)**: поддержка моделей без VPN (например, `google/gemma-4-31b-it:free`).
- **Google Gemini**: бесплатный официальный API-ключ.
- **Любой OpenAI-совместимый провайдер**: DeepSeek (`deepseek-chat`), Groq, OpenAI, локальные модели Ollama/LM Studio.
- **Настройка личности**: встроенный редактор системного промпта («внушение» характера и поведения нейросети).

### 💬 Долговременная память
- Все диалоги сохраняются в `chat_history.json`.
- При перезапуске история восстанавливается, а ИИ помнит прошлые темы разговора.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
Убедитесь, что на компьютере установлен **Python 3.10+** (Windows), затем выполните:
```bash
pip install -r requirements.txt
```

### 2. Запуск
Просто дважды кликните по файлу:
```bash
start_astrid.bat
```
*(или в командной строке: `python main.py`)*

## ⚙ Настройка нейросети (API)

1. В правом верхнем углу окна нажмите **`[ ⚙ НАСТРОЙКИ ИИ И КЛЮЧЕЙ ]`**.
2. Выберите провайдера:
   - **OpenRouter (Рекомендуется для РФ, бесплатно и без VPN)**:
     - Получить ключ: [openrouter.ai/keys](https://openrouter.ai/keys)
     - Базовый адрес API: `https://openrouter.ai/api/v1`
     - Имя модели: `google/gemma-4-31b-it:free`
   - **Google Gemini**:
     - Бесплатный ключ: [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
     - Имя модели: `gemini-3-flash-preview`
   - **DeepSeek**:
     - Базовый адрес API: `https://api.deepseek.com`
     - Имя модели: `deepseek-chat`
3. Нажмите **«Сохранить настройки»**.
