# ⚡ Ас3д (Astrid) // Cyber Assistant

> Умный голосовой и текстовый ассистент с киберпанк/матричным интерфейсом, поддержкой гибких пресетов и интеграцией с нейросетями (Gemini, OpenAI, DeepSeek, Groq, OpenRouter).

---

## 🌟 Возможности

- **🎙 Полноценный режим «Live» (как Яндекс Алиса или Алекса)**:
  - Фоновое ожидание кодового слова: просто скажите в микрофон **«Астрид»** или **«Астрид, включи ютуб»**.
  - Звуковой сигнал активации («динь-дон») и автоматическое распознавание речи.
  - Живая нейросетевая озвучка ответов красивым голосом («Светлана» от Microsoft Edge Neural TTS).
  - Кнопка **«🎤 СКАЗАТЬ»** для однократного быстрого ввода голосом без кодового слова.
  - Переключатель озвучки `[ 🔊 ОЗВУЧКА: ВКЛ / ВЫКЛ ]` в шапке.
- **🖥 Стильный хакерский терминал (Matrix Theme)**: полностью тёмный интерфейс с неоновой подсветкой, отображением логов действий и статуса системы.
- **💬 Долговременная память и сохранение истории**: переписка автоматически сохраняется в `chat_history.json`, а ИИ помнит контекст диалога.
- **⚡ Мощный визуальный редактор пресетов**:
  - Создавайте цепочки действий в пару кликов: запуск любых программ (`.exe`, ярлыки, батники через проводник), сайтов (URL), паузы между действиями и системные команды.
  - Пример: пресет `"youtube"` сначала запускает `happ.exe` (VPN), ждет 1 секунду и открывает `https://www.youtube.com`.
  - Привязка ключевых слов (триггеров) для запуска голосом или текстом (`ютуб, youtube, ютубчик`).
- **🧠 Универсальная интеграция с нейросетями**:
  - **Google Gemini**: бесплатный ключ из Google AI Studio (`gemini-2.5-flash`).
  - **Любой OpenAI-совместимый провайдер**: OpenAI (`gpt-4o`), DeepSeek (`deepseek-chat`), Groq, OpenRouter или локальные модели (Ollama, LM Studio).
  - **Кастомизация личности**: прямо в окне настроек можно задать характер и системный промпт ("внушение") для ИИ.
- **🛡 Безопасность для GitHub**:
  - Ваши персональные API-ключи и история чата хранятся только локально и автоматически игнорируются git (`.gitignore`).
- **🚀 Автономность**:
  - Астрид отлично работает даже **без интернета и без API-ключа** (в локальном режиме пресетов).

## 🚀 Быстрый запуск

### 1. Установка зависимостей
Убедитесь, что установлен Python 3.10+ на Windows, затем выполните:
```bash
pip install -r requirements.txt
```

### 2. Запуск
Просто дважды кликните по:
```bash
start_astrid.bat
```
Или в терминале:
```bash
python main.py
```

## ⚙ Настройка API-ключа (опционально)
1. В правом верхнем углу окна нажмите кнопку **`[ ⚙ НАСТРОЙКИ ИИ И КЛЮЧЕЙ ]`**.
2. Выберите провайдера:
   - **Google Gemini** (бесплатный ключ на [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey))
   - **OpenAI / DeepSeek / Groq / OpenRouter** (вставьте ключ и при необходимости укажите Base URL и модель).
3. При желании отредактируйте текст в поле **«Промпт Личности»** — там задаётся характер и поведение Астрид.
4. Нажмите **«Сохранить настройки»**.
